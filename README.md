# Grocery Store Management using SQL

## 📌 Project Overview
The **Grocery Store Management using SQL** project is designed to manage and analyze the operations of a grocery store using a relational database system.  
This project demonstrates how SQL can be used to organize business data, maintain relationships between entities, and generate valuable business insights through analytical queries.

The database includes information about:
- Suppliers
- Product Categories
- Products
- Customers
- Employees
- Orders
- Order Details

The project also contains advanced SQL analysis queries to evaluate:
- Customer purchasing behavior
- Product performance
- Sales trends
- Supplier contributions
- Employee performance
- Order-level insights

# 🗂 Database Schema

## Tables Used

### 1. Supplier
Stores supplier information.

| Column Name | Data Type |
|-------------|-----------|
| sup_id | TINYINT |
| sup_name | VARCHAR(255) |
| address | TEXT |

---

### 2. Categories
Stores product category details.

| Column Name | Data Type |
|-------------|-----------|
| cat_id | TINYINT |
| cat_name | VARCHAR(255) |

---

### 3. Employees
Stores employee information.

| Column Name | Data Type |
|-------------|-----------|
| emp_id | TINYINT |
| emp_name | VARCHAR(255) |
| hire_date | VARCHAR(255) |

---

### 4. Customers
Stores customer information.

| Column Name | Data Type |
|-------------|-----------|
| cust_id | SMALLINT |
| cust_name | VARCHAR(255) |
| address | TEXT |

---

### 5. Products
Stores grocery product details.

| Column Name | Data Type |
|-------------|-----------|
| prod_id | TINYINT |
| prod_name | VARCHAR(255) |
| sup_id | TINYINT |
| cat_id | TINYINT |
| price | DECIMAL(10,2) |

---

### 6. Orders
Stores customer order information.

| Column Name | Data Type |
|-------------|-----------|
| ord_id | SMALLINT |
| cust_id | SMALLINT |
| emp_id | TINYINT |
| order_date | VARCHAR(255) |

---

### 7. Order Details
Stores detailed information about each order.

| Column Name | Data Type |
|-------------|-----------|
| ord_detID | SMALLINT |
| ord_id | SMALLINT |
| prod_id | TINYINT |
| quantity | TINYINT |
| each_price | DECIMAL(10,2) |
| total_price | DECIMAL(10,2) |

---

# 🔗 Database Relationships

- A supplier can supply multiple products.
- A category can contain multiple products.
- A customer can place multiple orders.
- An employee can process multiple orders.
- An order can contain multiple products.
- Products are connected to orders through the `order_details` table.
